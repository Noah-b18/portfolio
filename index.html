Projet Upérion - Modélisation de Mini-Fusée

Le projet Upérion est un projet personnel mêlant sciences physiques, ingénierie et programmation. J'ai conçu et modélisé une mini-fusée pour explorer mes passions scientifiques et techniques. L'objectif principal était de créer un modèle réaliste et fonctionnel, puis de simuler son vol pour prédire ses performances. Ce projet m'a permis de développer mes compétences en CAO, simulation physique, et programmation, en affrontant des défis techniques complexes et en apprenant de façon autonome.

Modélisation 3D

Conception de la fusée Upérion avec attention aux détails aérodynamiques et structurels. Utilisation du logiciel Fusion 360 pour créer un modèle fonctionnel et scalable. Plus tard j'ajouterai un système électronique afin de recueillir des données lors du lancement et commander l'éjection du parachute.

    • Simulation Unity

    Développement d'une simulation de lancement sur Unity pour tester les performances théoriques de la fusée. La simulation intègre la physique réaliste du vol et permet de visualiser la trajectoire et le comportement de la fusée.

    Aperçu du code C# nécessaire pour le décollage de la fusée :

    
using UnityEngine;
public class RocketPhysics : MonoBehaviour
{
    public float mass = 0.15f;
    public float maxBurnTime = 0.2f;
    public float burnTime =
    private float timeSinceLaunch = 0f;
    private Rigidbody rb;
    private bool launched = 
    void Start()
    {
        rb = GetComponent();
        rb.mass = mass;
    }

    void Update()
    {
        if (Input.GetKeyDown(KeyCode.Space))
        {
            launched = true;
            timeSinceLaunch = 0f;
        }
    }

    void FixedUpdate()
    {
        if (!launched) return;
    
        timeSinceLaunch += Time.fixedDeltaTime;
    
        float thrust = GetThrust(timeSinceLaunch);
    
        Vector3 force = transform.up * thrust;
    
        rb.AddForce(force);
    
        ApplyDrag();
    }

    float GetThrust(float t)
    {
        if (t < maxBurnTime)
            return Mathf.Lerp(0, 15f, t / 0.2f);
        else if (t < burnTime)
            return 5f;
        else
            return 0f;
    }

    void ApplyDrag()
    {
        float rho = 1.2f; // densité air
        float Cd = 0.75f; // coef de trainée appro pour la fusée
        float A = 0.00091f; // surface frontale pour un diamètre de 17mm
    
        Vector3 v = rb.linearVelocity;
        float speed = v.magnitude;
    
        Vector3 drag = -0.5f * rho * Cd * A * speed * speed * v.normalized;
    
        rb.AddForce(drag);
    }
}

    Pièce de test

    J'ai modélisé une pièce destinée à tester la charge que pouvaient porter des robots-bras. Cette pièce se fixe directement au robot et permet d'accueillir des poids interchangeables de différentes masses afin d'évaluer la performance et la tenue mécanique sous charge.

    J'ai conçu la partie structurelle, en prévoyant des points de fixation robustes et un espace pour insérer des masses variées. L'objectif était d'obtenir une pièce modulable, simple à monter et suffisamment rigide pour des essais de charge répétés sur les axes linéaires industriels.

    Start & Scale — La start-up pour les jeunes entrepreneurs

    Start & Scale est une startup que j’ai cofondée avec deux camarades de lycée, née d’une idée simple : rendre l’accompagnement entrepreneurial accessible aux jeunes qui veulent lancer leurs projets mais n’ont ni réseau ni structure.

    À l’origine, le projet part d’un site vitrine assez classique, mais il évolue rapidement vers une logique plus ambitieuse : créer un écosystème complet permettant d’accéder à des services entrepreneuriaux à la demande. C’est cette évolution qui a donné naissance aux différentes versions du projet.

    Mon rôle dans Start & Scale s’inscrit à la fois sur le plan technique et opérationnel en tant que CTO et COO. J’ai participé à la conception et au développement des premières versions du site, puis à la structuration de l’évolution vers une plateforme plus complexe.

    Le projet a connu plusieurs itérations, notamment une V2 du site vitrine ainsi qu’une version de démonstration de la plateforme, hébergée sur Vercel, permettant de simuler les parcours utilisateurs et la logique de services.

    Techniquement et fonctionnellement, ce projet m’a permis de travailler sur plusieurs axes concrets :

    • Développement front-end de sites complets et responsives
    • Structuration d’une évolution produit (vitrine → plateforme)
    • Mise en place de logiques de services à la demande (concept de crédits)
    • Intégration de parcours utilisateur et formulaires dynamiques
    • Déploiement et gestion de versions sur Vercel
